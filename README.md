# mauricezeegers.nl

Source of [mauricezeegers.nl](https://mauricezeegers.nl), the personal page of Maurice Zeegers, Professor of Complex Genetics and Epidemiology at Maastricht University. It shows small dashboards on research, trail running, beekeeping and a holiday house in the Mani, Greece.

## How it works

* `index.html` is the whole site: one page with tabs (Home, Vacation house, Beekeeping, Trail running, Research), plain HTML, CSS and JavaScript, served by GitHub Pages.
* All figures live in one JSON block, `<script id="site-data">`. The comments just above it describe every field.
* A scheduled job refreshes that block and `sitemap.xml` once a week from the original sources (publication list, OpenAlex, sports watch, hive app, weather sites, rental calendars). Everything else is edited by hand.
* `scripts/hivecompanion_to_json.py` converts the export of the HiveCompanion beekeeping app.
* `llms.txt`, `robots.txt`, `sitemap.xml` and the JSON-LD in the page head help search engines and AI agents.

## Privacy

Only aggregates are published: weekly running totals (no routes, GPS or times), hive data without apiary locations, and blocked dates of the house without guest details.
